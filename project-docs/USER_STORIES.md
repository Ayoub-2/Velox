# User Stories

## Design Phase
*   **US-001**: As a developer, I want to search for "Secure Authentication for Microservices" so that I can choose the right pattern (e.g., OIDC/OAuth2) before writing code.
*   **US-002**: As an architect, I want a checklist of "Top 10 Security Risks" for my specific technology stack (e.g., Node.js + AWS).

## Implementation Phase
*   **US-004**: As a developer, I want clear code examples of how to implement Input Validation for my specific framework.
*   **US-DAST**: As a developer/tester, I want to run a quick DAST scan on my staging URL from the dashboard to catch common vulnerabilities (XSS, SQLi) before merging.

## Review Phase
*   **US-005**: As a reviewer, I want a generated "Security Scorecard" for a pull request to see if it meets baseline standards.
