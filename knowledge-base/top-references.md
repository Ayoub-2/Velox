# Top References for Deep Research

When conducting deep security research or designing secure systems, relying on authoritative standards and up-to-date databases is crucial. This guide provides a curated list of the most important references in the industry.

## 1. Standards & Frameworks

### OWASP (Open Web Application Security Project)
The primary source for web security.
*   **[OWASP Top 10](https://owasp.org/www-project-top-ten/)**: The standard awareness document for developers and web application security.
*   **[ASVS (Application Security Verification Standard)](https://owasp.org/www-project-application-security-verification-standard/)**: A detailed list of security requirements and controls.
*   **[Cheat Sheet Series](https://cheatsheetseries.owasp.org/)**: Actionable guides for specific topics (e.g., Authentication, CSRF).

### NIST (National Institute of Standards and Technology)
US government standards often adopted globally.
*   **[NIST SP 800-53](https://csrc.nist.gov/publications/detail/sp/800-53/rev-5/final)**: Security and Privacy Controls for Information Systems.
*   **[NIST SP 800-63 (Digital Identity Guidelines)](https://pages.nist.gov/800-63-3/)**: The gold standard for authentication and lifecycle management.

### CWE (Common Weakness Enumeration)
A community-developed list of software and hardware weakness types.
*   **[CWE Top 25](https://cwe.mitre.org/top25/archive/2023/2023_cwe_top25.html)**: The most dangerous software weaknesses.

## 2. Vulnerability Databases

*   **[CVE (Common Vulnerabilities and Exposures)](https://cve.mitre.org/)**: The dictionary of publicly known cybersecurity vulnerabilities.
*   **[NVD (National Vulnerability Database)](https://nvd.nist.gov/)**: The U.S. government repository of standards based vulnerability management data.

## 3. Attack Methodologies

### MITRE ATT&CK
A globally-accessible knowledge base of adversary tactics and techniques based on real-world observations.
*   **[ATT&CK Matrix for Enterprise](https://attack.mitre.org/matrices/enterprise/)**: Mapping of attack techniques to tactics (e.g., Initial Access, Persistence).

## 4. Tools & Playgrounds

*   **[PortSwigger Web Security Academy](https://portswigger.net/web-security)**: Free training labs from the creators of Burp Suite.
*   **[PentesterLab](https://pentesterlab.com/)**: Hands-on exercises for web vulnerabilities.
*   **[Project Discovery](https://projectdiscovery.io/)**: Home of Nuclei, allowing for template-based scanning.

## 5. Cryptography

*   **[Cryptographic Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)**: Best practices for storing secrets.
*   **[Latacora's Cryptographic Right Answers](https://latacora.micro.blog/2018/04/03/cryptographic-right-answers.html)**: No-nonsense advice on what crypto libraries and primitive to use.
